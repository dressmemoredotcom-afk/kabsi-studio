# Video studio

One video studio for two unrelated brands. They share only brand-neutral engine code.

- **Kabsi** (`kabsi/`): kabsi.co, which looks after a local business's Google Business Profile. Videos follow
  `kabsi/docs/VIDEO-PLAN.md`.
- **Roomy Properties** (`roomy/`): Beirut real estate. Listing reels built from one file per listing.

**The brands never mix.** Nothing of one brand appears in the other's folder, code, config, assets, rule check,
workflow or docs. `engine/` holds no colours, fonts, words or media. `npm run check` fails if either rule breaks.

## Layout

```
engine/src/       anim, frame, timeline, audio (AudioMix, mix, sfx)
engine/scripts/   tts (Kokoro), render-core (Remotion, -14 LUFS master, poster), contact-sheet, make-audio,
                  isolation, file-size
kabsi/            CLAUDE.md, config.json, docs/, src/, public/ (brand/, audio/, voice/, inputs/<ID>/), scripts/, out/
roomy/            CLAUDE.md, config.json, docs/, src/, public/ (brand/, audio/, voice/, media/<property>/),
                  listings/<id>.json, scripts/, out/
```

Each brand's `public/` is its Remotion public dir. Review packages in `kabsi/out/<ID>/` and `roomy/out/<id>/` are
committed: the video, the poster, contact sheets (2 frames a second) and `script.txt`.

## Commands

| Command | What it does |
| --- | --- |
| `npm run kabsi:studio` | Remotion Studio on the Kabsi entry. |
| `npm run kabsi:check` | Kabsi rule check. |
| `npm run kabsi:render -- <ID>` | Render one Kabsi video into `kabsi/out/<ID>/`. |
| `npm run kabsi:voice -- <ID>` | Make that video's voice lines. |
| `npm run kabsi:checklist -- <ID>` | Rewrite that video's `checklist.md` from its review package. |
| `npm run kabsi:voice-test` | Rewrite `kabsi/out/voice-test/`: two lines in the five Kabsi voices, with measurements. |
| `npm run roomy:studio [-- <id>]` | Remotion Studio on the Roomy entry, on one listing. |
| `npm run roomy:check` | Roomy rule check, every listing. |
| `npm run roomy:render -- <id>` | Render `roomy/listings/<id>.json` into `roomy/out/<id>/`. |
| `npm run roomy:voice -- <id>` | Make that listing's voice-over. |
| `npm run roomy:assets [-- <id>]` | Record which photos, clips, logo and music exist. |
| `npm run check` | Both brands' checks, the isolation check and the file-size check (no tracked file over 45 MB). |
| `npm run build` | Type check, lint, check, then a bundle of each brand's entry. Must pass before a push. |

`node engine/scripts/make-audio.mjs <out-dir>` generates stand-in sound effects and music loops into a folder.

Workflows: `check` runs `npm ci` and `npm run build` on every push. `render-kabsi` (input: video ID) and
`render-roomy` (input: listing id) run from the Actions tab and upload the output folder as an artifact.

Needs Node 22 or newer and FFmpeg with libx264 on the PATH. Remotion downloads its own headless Chrome on first run;
set `CHROME_PATH=/path/to/chrome` to use an installed one.
